Curso 4: Uso Básico de Internet en la Práctica Docente

Unidad Especializada de Formación Continua (UNEFCO)

Bienvenido a la guía interactiva paso a paso. Marca las casillas a medida que completes cada acción para llevar un registro de tu progreso. ¡Comencemos!

Parte 1: Creación de una cuenta en GitHub

GitHub será nuestra "nube" personal donde guardaremos y publicaremos nuestros juegos interactivos para que los estudiantes puedan acceder a ellos mediante un enlace.

Parte 2: Lluvia de Ideas (Brainstorming) para el Juego

Antes de pedirle a la Inteligencia Artificial que programe nuestro juego, debemos tener claro qué queremos enseñar.

Parte 3: Diseño de Prompt (Instrucción para la IA)

Para generar el juego sin saber programar, usaremos un "Prompt" (una instrucción detallada) en herramientas como ChatGPT, Claude o Gemini. La fórmula mágica es: Rol + Tarea + Contexto + Formato.

💡 Ejemplo de Prompt para Copiar y Pegar:
"Actúa como un desarrollador web experto en educación. Crea un juego interactivo de emparejar conceptos. El tema es [INSERTA TU TEMA AQUÍ]. El juego debe ser visualmente atractivo, con colores llamativos y mensajes de felicitación al terminar. Entrégame el resultado en un único bloque de código HTML (con CSS y JS integrados) listo para copiar, pegar y funcionar."

Parte 4: Creación de GitHub Pages (Publicar el Juego)

Una vez que la IA te dé el código, ábrelo en el Bloc de Notas de tu computadora, pégalo, y guárdalo como index.html. Ahora, ¡vamos a publicarlo gratis en internet!
